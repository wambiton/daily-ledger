# 界面截图说明

本目录图片用于帮助试用者了解软件外观。拍摄日期：2026-10-21。

## 来源与范围

- 正式应用版本：0.7.10-capture-status，versionCode 21。
- 设备：realme GT7，Android 16。
- 使用安卓测试入口调用现有 HomeDashboard、ComparisonScreen 和 BudgetScreen 组件，在独立测试容器中真机渲染；不是设计效果图。
- 截图保留组件本身的布局，没有完整应用底部导航、账号区和自动记账全局状态。实际屏幕显示随设备尺寸和字体设置变化。
- 所有账目、备注、预算、分类均为模拟数据。使用UUID命名的独立测试数据库与主题偏好，不读取正式账本。
- 图片直接由 Compose 根节点捕获，无后期数字替换、账户信息覆盖或系统状态伪造。

## 维护者复现

截图入口：`android/app/src/androidTest/java/com/personal/ledger/ShowcaseCaptureTest.kt`。仅在明确传入 `gallery=true` 时执行，常规账号回归脚本已排除此入口。

先构建测试包，并在与测试代码兼容的已授权设备上安装测试APK。优先使用测试设备；测试运行会占用前台，不要在用户操作手机时启动。

```powershell
./scripts/android.ps1 -Tasks assembleDebugAndroidTest
# 把 <serial> 替换为 adb devices 中实际选择的设备序列号
adb -s <serial> install -r android/app/build/outputs/apk/androidTest/debug/app-debug-androidTest.apk
adb -s <serial> shell am instrument -w -e class com.personal.ledger.ShowcaseCaptureTest -e gallery true com.personal.ledger.test/androidx.test.runner.AndroidJUnitRunner
```

图片在目标应用私有缓存 `cache/github-gallery/` 中，通过 `adb exec-out run-as com.personal.ledger cat` 按文件导出二进制。不要用会重新编码输出的文本重定向保存PNG。

演示日期随运行当天变化；不应把动态截图当作固定日期的业务测试基准。测试结束取消该模拟账本的预算和回收站定时任务，保留模拟库供检查，不删除用户原账目。发布前逐张检查没有个人信息，并检查README图片路径。
