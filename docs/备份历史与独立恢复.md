# 备份历史与独立恢复

适用于手机 0.7.13 开发版和包含历史接口的新版电脑服务。当前公开电脑端 0.7.0 不提供此入口所需接口，需要后续更新交付包。本功能尚待真机验收，不是已发布版本说明。

1. 打开电脑备份程序，手机连接该电脑并登录对应账号。
2. 进入“我的”中的账号管理，点击“备份历史 / 恢复为独立账本”。历史只属于当前账号在该电脑上的成功备份，按版本从新到旧排列，可加载更早版本。
3. 选择一个版本，查看恢复预览：正常账目、回收站账目、日期范围和预算计划数量。
4. 确认“恢复为独立账本”。软件新建一份手机账本，当前账本的账目、待备份修改、账号与自动记账目标都保留。
5. 点击“查看恢复的账本”，或以后从“查看 / 切换手机账本”打开。新账本可离线查看，不会自动上传到账号。

若需要将其中账目放回账号，可使用既有“从手机账本导入”，预览并勾选后追加；重复账目仍须明确选择是否再次导入。该追加功能针对账目，不能将它理解为预算计划合并。

独立恢复保留备份中的预算计划。回收站按原删除时间继续计时：超过30天的记录不恢复，预览后到期的记录也不会因恢复重新获得30天。电脑原有历史快照不会被此次操作修改或删除。

新手机首次登录自动读取最新备份的既有规则保持不变；历史恢复是额外的手动找回方式。旧电脑服务、连接失败、版本不匹配或备份内容无效时，会显示错误，不用空数据替换当前账本。
