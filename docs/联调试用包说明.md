# 个人记账 · 联调试用包

本文件夹包含安卓 APK、电脑端 ZIP、使用说明和 SHA256 校验清单。此次提供本地试用，不改变 GitHub 公开下载。

## 安装与升级

1. 手机安装本文件夹的 APK，选择覆盖更新。不要卸载旧应用或清除数据；若签名不兼容，请停止并反馈，不要为安装而删除账目。最低 Android 8.0。
2. 电脑先退出旧程序及托盘图标，再完整解压电脑端 ZIP，运行 LedgerBackup/LedgerBackup.exe。保留旁边整个 _internal 文件夹，不要在压缩软件内直接运行。
3. 本包手机版本为 0.7.13-backup-history；电脑内部仍显示 0.7.0，但本包重新构建后支持备份格式1—5。以本包“构建信息.json”和 SHA256 清单识别构建，不要拿旧公开电脑包替换。
4. 核对电脑窗口的账号数据目录仍为原目录；若不一致，使用“选择原账号数据目录”。不要删除、搬空或覆盖原账号目录。
5. 手机重新扫描这台电脑当前二维码，用原账号登录。发信 QQ 邮箱及 SMTP 授权码仍由用户在自己的电脑上设置；交付包不含任何账号或授权码。

## 备份与恢复

点击“备份到电脑”，以本次明确显示“备份成功”为准；历史成功时间不等于本次成功。换机前先确认原手机上传成功，再在新手机连接同一电脑、登录同账号。仅在原手机保存且没有上传的账目无法自动出现在新手机。

历史版本恢复会创建独立账本供核对，不覆盖当前账本或直接替换电脑最新备份。详见“备份历史与独立恢复.md”。命名规则与确认状态需要本包支持v5的电脑端。

外出使用流量时，电脑需要开机并保持程序和外网连接服务运行。免费临时地址可能变化，届时需重新配对；电脑关闭时不能立即完成上传。

## 使用说明阅读顺序

先读本文件，再看“使用说明.md”的具体功能。后者保留旧版迭代说明，其中0.6.1/0.7.0标题是历史记录，不是本次要求降级的版本。

## 已验证与边界

实际手机与实际电脑EXE通过USB转发完成两版v5备份、历史恢复、规则和账号隔离测试。电脑重启登录与密码修改测试通过。测试使用独立模拟数据，原有804份数据库业务字段核对无增删改。

本轮没有重新验收公网流量、扫码界面、真实邮件、多台物理手机和其他Windows电脑；也不保证微信/支付宝每次都发出可识别通知。完整范围见“验收状态.txt”。APK为调试试用构建，尚非应用商店正式发行包。

反馈时请附手机/Windows版本、操作步骤、错误提示和大概时间。不要发送密码、SMTP授权码、完整账单或未打码的通知内容。
