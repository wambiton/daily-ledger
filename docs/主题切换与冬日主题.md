# 外观与主题

入口：我的 → 外观与主题。

- 默认主题：保留原有蓝白配色和账本布局。
- 雪乃·冬日：冰蓝、白色、深蓝文字；动画风人物和Q版人物横幅，当前账本本月收入/支出/结余，当前预算计划的整期进度，沿用原有今日账目与日历查看方式。
- 点击“使用此主题”立即生效，选中的主题显示“正在使用”；随时可切回默认。设置保存在本机，应用重启仍保留，切换账号不改变外观，不随账号备份上传。
- 多月预算不平摊成虚构的月预算，卡片明确展示起止月份及整期预算；未知主题设置回退默认。
- 主题只改变展示，不导入、删除或修改账目，不改变记账、通知读取、分类、预算提醒或备份规则。

## 图片来源

`android/app/src/main/res/drawable-nodpi/winter_yukino.png` 为本次使用内置图像生成工具制作的雪乃主题插画，包含动画风人物与Q版人物，非官方素材或动画正片截图。用户提供的社交平台截图只作为视觉参考，没有将网页按钮、作者信息或示例账目打包进应用。文字、金额、进度均由原生界面渲染，图片不承载实际账目数据。

版本：Android 0.7.2-themes（13）。电脑备份程序继续使用0.7.0，协议未变。
