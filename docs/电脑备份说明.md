# 电脑本地备份

按用户要求，当前先使用电脑文件夹保存手机账目备份，云端方案保留待后续实施。

- 位置：`D:\软件开发\电脑账目备份\`，每次生成独立时间子目录，不覆盖历史备份。
- 手机通过USB连接，开启USB调试并授权电脑后，运行：

```powershell
.\.venv\Scripts\python.exe scripts/backup_phone.py --serial 3B159R0037100000
```

- 脚本短暂停止记账应用，复制数据库及未合并的WAL，生成独立SQLite快照，完成后重新打开应用。先保存正在编辑的账目。
- `ledger.sqlite3`包含分类、账目、待同步操作和同步状态；`manifest.json`包含备份时间和SHA256校验值。
- 备份含个人账目，未加密，请保存在自己控制的电脑上；整个文件夹已排除Git提交。
- 当前为开发版USB手动备份，不是自动同步；正式版应用内导出/恢复、自动备份入口仍需实现。
- 已验证数据库完整性、外键关联，以及合成测试中WAL数据完整保留。尚未将备份覆盖恢复到真实手机，以免影响现有账目；恢复功能验收尚未完成。
