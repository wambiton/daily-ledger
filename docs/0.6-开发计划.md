# 0.6 账目保护与文件备份

用户已确认：清晰显示备份状态；支持 Excel 文件及可恢复备份文件；支持全部账目或指定日期范围；回收站保留30天；文件导入只追加，重复账目可跳过或仍然新增一笔。

可恢复文件包含范围内的正常账目和回收站账目，导入保留原删除时间，不重算30天。Excel只包含正常账目。导入过期回收站记录时跳过，不使其重新出现。日期范围按账目日期，包含起止两天。

1. 回收站：删除移入回收站，恢复后重新计入统计；到期自动清理，应用打开时补充清理。设备关闭或系统限制后台运行时，不能承诺到秒清理。验证30天边界、账本隔离、恢复和原数据保留。
2. 文件导入导出：系统文件选择器；Excel及JSON备份；追加前显示预览与重复数量；支持旧格式，拒绝损坏文件且事务回滚。电脑备份同步兼容含回收站的新格式。
3. 备份状态：区分手机保存、待上传、上传中、等待连接及最近成功时间；待上传笔数按账目去重，不把分类操作当作账目。
4. 验收与交付：各阶段测试后独立本地提交。升级前保护真实数据库，覆盖安装不清空数据。重新打包电脑端、手机端及说明；免费外网通道原有未验收限制继续如实记录。

备份文件不包含密码、授权码或登录令牌。历史备份文件中的副本不会被手机回收站自动清理；恢复时仍按原删除时间判定过期。
