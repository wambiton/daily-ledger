# 账号与手动电脑备份

## 当前方案

使用QQ邮箱验证码注册、邮箱和独立应用密码登录。不同账号的手机账本分别保存，电脑端按登录账号隔离版本快照。平时只在手机记账，点击“备份到电脑”才上传；换手机后登录同一账号，自动加载最近一次成功备份的账目。

当前完成本机USB联调，不具备外网访问入口。用户已决定先完成本机功能；域名、内网穿透及公网HTTPS留待下一步。不要把当前仅绑定127.0.0.1的开发服务器直接暴露公网。

## 本机使用

1. 双击项目根目录的 `打开QQ邮箱配置.cmd`（完整位置：`D:\软件开发\打开QQ邮箱配置.cmd`），打开“QQ邮箱 SMTP 配置”窗口，填写QQ发信邮箱及SMTP授权码，点击“保存到本机”。授权码不是QQ登录密码，不要粘贴到聊天里。配置使用Windows当前用户的DPAPI加密保存，保存在不进入Git的备份目录中。
2. 双击根目录 `启动电脑备份服务.cmd`，重新加载配置并启动后台服务。入口会等待健康检查通过，显示实际启动结果；更改邮箱配置后再次双击即可重启。服务日志位于`电脑账目备份/账号服务/server-output.log`和`server-error.log`。保持电脑开启，当前服务只监听本机，不提供外网入口。
3. 手机USB连接并授权调试后，双击`启动电脑备份服务.cmd`。入口会自动为唯一一台已授权手机建立USB通道；显示“手机USB通道已连接”后即可使用。电脑重启、服务退出或重新插拔USB后，再次双击即可恢复连接。
4. 手机“我的”中填写 `http://127.0.0.1:8765`，选“注册”，输入QQ邮箱、应用密码（至少8位，不限制字符类型）并获取验证码；注册后登录账号。
5. 首次注册成功自动带入原本机账目。已经注册过的账号可点“导入原本机账目”追加，账号有账目或已备份均可导入。重复导入会提示，选择继续则新增相同账目，原账目保留，两笔都计入统计；取消则不导入。
6. 点击“备份到电脑”上传当前账号账目。版本、笔数与时间直接显示在页面。原本机账本始终保留，退出账号可以查看。新手机只能找回已成功上传的账目，未上传修改仍只在原手机。

HTTP仅限开发版的127.0.0.1 USB通道，外网地址必须HTTPS。正式版本不会允许该HTTP例外。

## 数据与恢复规则

- 电脑目录：`电脑账目备份/账号服务/`。`accounts.sqlite3`保存账号及所有备份版本，`server-secret.txt`用于验证码摘要；整个目录不可提交Git，也不可当静态网页公开。
- 电脑快照含分类、有效账目、金额、所属日期、备注及创建/修改时间，不含手机登录令牌。删除后备份形成新的快照，旧快照仍保留。
- 上传使用版本检查及唯一请求ID。请求响应丢失可重试；另一台设备已产生新版本时拒绝旧版本覆盖。登录时无未上传修改的账号可自动加载更新版本；有未上传修改时保留手机账目并提示冲突，不自动合并多台设备的未上传修改。多设备同时修改的冲突处理界面尚未提供。
- “我的”保留“备份到电脑”和“导入原本机账目”，移除“查看电脑备份”“从电脑恢复”。换机登录完成备份加载后才切换到账号账本；已有本机未备份修改不会被自动替换。
- 导入来源ID随备份保存，换机仍可判断重复导入；Room 1→2升级只新增来源记录表，保留旧账目。
- 登录令牌由Android Keystore加密保存；密码、验证码不持久化。退出账号不删除其手机账目。服务器地址变更会使用独立本地账本，需重新登录并恢复，不能随意把地址换成不可信站点。
- 电脑关闭或服务未运行时，新登录显示“电脑尚未连接，请等候”，每5秒间隔重试，可取消等候。连接恢复后继续，不提前显示空账号账本。应用被系统结束后需要重新登录；密码不写入持久化存储。已经登录的手机仍可离线记账。
- 注册请求提交后若响应丢失，不自动重复注册，避免重复创建账号；可用同一邮箱登录，必要时通过“导入原本机账目”追加原账本。
