# 银行短信与支付宝自动记账（0.7.11 测试版）

## 开启

覆盖安装新版，保留已有数据。进入“我的 → 自动记账”，确认固定目标账本及自动记账总开关已开启，再打开“银行短信自动记账”，允许系统的短信权限请求。

短信只处理开启后新收到的消息，不读取历史短信。目前支持招商银行 95555、带“【招商银行】您账户…于…快捷支付/消费/存入/退款…”的已适配模板，不代表支持所有银行或所有招商银行短信。验证码、普通消息不保存。

## 入账与合并

- 普通消费记支出，存入记收入，退款另记收入而不冲减原支出。明确的本人互转、充值和提现不计收支。
- 沿用已确认的商户分类；短信没有分类规则时使用“其他支出”或“其他收入”，退款使用“退款”。
- 同一固定账本内，银行短信与微信/支付宝通知按渠道、金额、收支方向、退款标记及五分钟交易时间窗口一对一配对。两条来源只生成一笔统计；不会跨账本合并。
- 自动判断仍可能把相近的不同交易合并。进入“已处理”，查看账目与来源，选择“这不是同一笔，拆分此来源”，确认后保留两笔且均计入统计。重复打开或再次处理同一来源不会再次入账。
- 来源和合并关系保存在当前手机，正式账目按原有备份流程保存到电脑。

## 支付宝漏记如何核对

“连接与后台设置”会区分最近收到支付宝通知、最近匹配支付信息和未匹配原因。支持读取通知的大文本、多行文本和普通正文；普通聊天/营销消息不会因为出现数字就记账。

支付宝应用内的“支付消息”页面不等于手机发出了系统通知。若系统没有发通知或隐藏了金额，通知识别无法获取账单；符合已适配模板的银行卡短信可作为另一条来源。没有通知、也没有支持的短信时仍需手动补记。

请在下一次正常消费后核对金额、时间、目标账本和来源；无需为测试额外消费。程序测试与模拟合并通过不等于所有真实银行/支付宝通知模板均已验证。
