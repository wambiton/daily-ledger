# 自动记账通知验证版

用户已授权：先做通知读取验证版，暂缓账单文件导入；仅处理开启之后的新微信/支付宝支付通知。指定固定账本，与当前查看账本无关。信息及分类明确时入账并通知；分类、金额或收支类型不明以及疑似手动重复时放待确认，不计统计/预算。退款收入不冲减原支出。充值、提现、本人账户互转不计收支。重复通知不重复记账；确认替换手动账目时移入30天回收站。

阶段1：保守支付通知解析、独立本机待确认数据库、跨账本固定目标、商户分类记忆、去重和事务写入；单元测试。
阶段2：通知监听服务、系统授权引导、固定账本选择、自动开关、诊断状态、待确认与历史入口，真实设备合成通知逻辑验证。
阶段3：保护真实记录后覆盖安装验证版，交付APK和操作说明；由用户下一次正常付款验证实际微信/支付宝通知内容。不代用户发起付款、不读取普通聊天原文、不要求支付密码，不启用无障碍或root。

限制：系统通知不等于应用内支付凭证；无通知/隐藏金额无法保证识别。当前模板为验证规则，分类只用用户确认的商户映射及退款分类，无法判断时保守待确认。待确认与商户映射仅保存在当前手机，正式入账后账目进入原有账号备份。上线状态需以真实支付场景验证为准。

## 0.7.1 验证版使用步骤

1. 手机打开“我的 → 自动记账（通知验证版）”，选择固定目标账本。之后查看其他账本不会改变自动记账目标。
2. 点击“打开通知使用权设置”，在系统页面允许个人记账读取通知，返回确认显示“通知读取：已连接”。
3. 打开“自动记账”开关，通过“设置记账结果通知”允许显示结果通知。默认不开启，不补读历史通知。
4. 下次正常付款后检查此页。首次识别的普通商户一般进入“待确认”，补齐金额/分类后确认入账；可勾选记住商户分类。信息完整且已有分类规则时可自动入账。
5. 疑似重复时可不入账、保留两笔，或将选中的原账移入回收站并保留新账。未确认的记录不参与统计和预算。
6. “已处理记录”可打开正式账目修改。备份仍通过原有“备份到电脑”，电脑端继续使用0.7.0；本轮未发布新的电脑程序。

诊断区的“应用通知”仅表示收到该应用的通知，不表示成功识别支付。“支付识别”更新后再检查待确认/已处理记录。如果两者未更新，先检查系统通知使用权、服务连接状态、目标账本和开关。不要为了测试额外消费，使用下一次正常付款验证即可。

当前日期按通知到达时的中国时区日期记录，延迟通知可在确认/修改时纠正。无系统通知、金额隐藏、模板不匹配均可能漏识别，验证期请核对真实支付记录。退款按收入入账，不冲减原支出；同一交易的多次部分退款不使用原交易号互相去重。
