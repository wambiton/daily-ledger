# 账号与手动电脑备份

## 当前方案

使用QQ邮箱验证码注册、邮箱和独立应用密码登录。不同账号的手机账本分别保存，电脑端按登录账号隔离版本快照。平时只在手机记账，点击“备份到电脑”才上传；换手机后登录同一账号并点击“从电脑恢复”。

当前完成本机USB联调，不具备外网访问入口。用户已决定先完成本机功能；域名、内网穿透及公网HTTPS留待下一步。不要把当前仅绑定127.0.0.1的开发服务器直接暴露公网。

## 本机使用

1. 双击项目根目录的 `打开QQ邮箱配置.cmd`（完整位置：`D:\软件开发\打开QQ邮箱配置.cmd`），打开“QQ邮箱 SMTP 配置”窗口，填写QQ发信邮箱及SMTP授权码，点击“保存到本机”。授权码不是QQ登录密码，不要粘贴到聊天里。配置使用Windows当前用户的DPAPI加密保存，保存在不进入Git的备份目录中。
2. 运行 `scripts/start_backup_server.ps1`，保持电脑与服务运行。后台方式加 `-Background`；后台启动返回的进程号用于后续停止该服务。更改邮箱配置后需重启服务。
3. 手机USB连接并授权调试，在电脑执行 `.tools/android-sdk/platform-tools/adb.exe -s 3B159R0037100000 reverse tcp:8765 tcp:8765`。
4. 手机“我的”中填写 `http://127.0.0.1:8765`，选“注册”，输入QQ邮箱、应用密码（12—128位）并获取验证码；注册后登录账号。
5. 已有未登录账目不会自动绑定账号。登录后的空账号可以点“导入原本机账目”，明确确认后复制；原账本保留，再点“备份到电脑”。
6. 点击“查看电脑备份”确认服务器版本、笔数与时间；备份失败不清除手机数据。重新插拔USB或电脑重启后需要重新建立端口转发。

HTTP仅限开发版的127.0.0.1 USB通道，外网地址必须HTTPS。正式版本不会允许该HTTP例外。

## 数据与恢复规则

- 电脑目录：`电脑账目备份/账号服务/`。`accounts.sqlite3`保存账号及所有备份版本，`server-secret.txt`用于验证码摘要；整个目录不可提交Git，也不可当静态网页公开。
- 电脑快照含分类、有效账目、金额、所属日期、备注及创建/修改时间，不含手机登录令牌。删除后备份形成新的快照，旧快照仍保留。
- 上传使用版本检查及唯一请求ID。请求响应丢失可重试；另一台设备已产生新版本时拒绝旧版本覆盖。恢复最新版本后可继续备份；不自动合并多台设备的未上传修改。
- “从电脑恢复”有明确的替换确认；恢复前保存当前账号安全副本于应用私有目录，数据库替换失败会回滚。此安全副本目前没有面向用户的恢复入口，需开发协助导出；不等同于可独立使用的备份历史页面。
- 登录令牌由Android Keystore加密保存；密码、验证码不持久化。退出账号不删除其手机账目。服务器地址变更会使用独立本地账本，需重新登录并恢复，不能随意把地址换成不可信站点。
- 电脑关闭或服务未运行时，注册/新登录/上传/恢复不可用；已经登录的手机仍可离线记账。
