# 预算开发计划（2026-09-24）

用户已确认开发：预算仅限当前账本，单月或连续多月计划，计划月份不能重叠。各月支出分类预算允许超过月均参考额，但全期分类分配合计不得超过总预算。支持未来月份、沿用上月且不覆盖已配置月份；可分配额度不足时提示调整。到期提示沿用上一期（相同时长/总額/逐月分配）、自主安排或暂不创建，绝不自动创建下一期。

计划总预算及每月分类预算分别在80%、100%提醒；直接跨越仅发100%。下降后再次越过阈值重新提醒。应用内与系统通知并行，通知未授权不影响应用内提醒。预算设置随账号电脑备份并在换机后恢复。

1. 数据与计算：Room非破坏性2→3迁移、计划/分配校验、只填未配置月份、阈值状态持久化。单元测试后独立提交。
2. 界面与通知：预算入口、列表和逐月编辑、详情统计、到期选择、系统权限与通知、当前账本隔离。真机验证，不清空真实账本。
3. 备份兼容：格式3携带预算，手机与电脑严格校验，旧格式仍可读取，旧电脑明确升级提示。恢复事务保留隔离，账目追加导入不擅自合并预算计划。
4. 集成验收与交付：完整回归、现有数据保护与比对、新版安装及电脑打包。未完成的外网/其他用户环境专项继续如实说明。
