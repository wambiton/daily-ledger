# 试用与反馈指南

感谢试用个人记账！当前重点是通过实际反馈完善体验，暂未添加开源许可证。源码公开不代表授予完整的开源使用许可。

## 第一次体验

1. 在[下载页](https://github.com/wambiton/daliy-app/releases/tag/v0.7.10)选择Android APK。最低Android 8.0；当前为调试签名试用包，并非所有机型都经过测试。
2. 先添加几笔模拟收入和支出，试试补记、分类、日历、搜索、多周多月比较与预算。
3. 需要电脑备份时下载Windows ZIP，完整解压并保留内部组件，按[备份说明](电脑端外网备份使用说明.md)配置自己的电脑。
4. 已有用户请覆盖安装并保留原数据；不要通过卸载、清空应用或删除电脑数据目录来解决问题。

## 当前限制

- 微信、支付宝自动记账依赖系统支付通知、通知使用权及手机后台设置，可能漏识别。银行卡短信记账尚未接入，不能期待当前版本自动采集。
- 日常账目保存在手机；只有明确显示本次电脑备份成功，才表示该次备份完成。历史成功时间不代表今天已成功上传。
- 免费外网通道需要电脑开机运行服务，地址可能变化，届时需要重新扫码。新手机只能恢复同一电脑中已成功备份的数据。
- 手机0.7.10与电脑0.7.0是此次配套组合。请报告双方实际运行的版本，不以下载文件名代替已安装版本。
- 测试阶段请为重要数据保留独立备份。无需为了验证功能额外消费。

## 提交反馈

登录GitHub后，打开[反馈入口](https://github.com/wambiton/daliy-app/issues/new/choose)，选择“发现问题”或“功能建议”。提交前可以先搜索[已有问题](https://github.com/wambiton/daliy-app/issues)，同样的问题可补充自己的设备情况。

问题反馈请说明：软件版本、设备系统、操作步骤、期望结果、实际提示，以及问题是否总能复现。拿不准时写“不清楚”，无需猜测原因。

自动记账问题请说明付款后系统是否显示通知，以及自动记账页面的连接状态；不要公开完整支付记录。备份问题请说明电脑是否在线、本次状态和两端版本。

所有Issue和附件均公开可见。不要提交密码、验证码、SMTP授权码、原始账本或数据库；截图请遮盖邮箱、银行卡号、交易对手和其他个人信息。

## 反馈之后

维护者会根据复现情况、影响范围与工作时间安排处理，可能需要你补充信息。提交建议不代表一定实现，也不承诺修复日期。无需提交代码，清楚描述问题就很有帮助。
