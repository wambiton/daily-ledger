# 备份历史与独立恢复

适用于手机 0.7.13 开发版和包含历史接口的新版电脑服务。2026-10-25 已通过真机及本机测试服务联调；当前公开电脑端 0.7.0 不提供此入口所需接口，需要后续更新交付包，尚未发布新版电脑安装包。

1. 打开电脑备份程序，手机连接该电脑并登录对应账号。
2. 进入“我的”中的账号管理，点击“备份历史 / 恢复为独立账本”。历史只属于当前账号在该电脑上的成功备份，按版本从新到旧排列，可加载更早版本。
3. 选择一个版本，查看恢复预览：正常账目、回收站账目、日期范围和预算计划数量。
4. 确认“恢复为独立账本”。软件新建一份手机账本，当前账本的账目、待备份修改、账号与自动记账目标都保留。
5. 点击“查看恢复的账本”，或以后从“查看 / 切换手机账本”打开。新账本可离线查看，不会自动上传到账号。

若需要将其中账目放回账号，可使用既有“从手机账本导入”，预览并勾选后追加；重复账目仍须明确选择是否再次导入。该追加功能针对账目，不能将它理解为预算计划合并。

独立恢复保留备份中的预算计划。回收站按原删除时间继续计时：超过30天的记录不恢复，预览后到期的记录也不会因恢复重新获得30天。电脑原有历史快照不会被此次操作修改或删除。

新手机首次登录自动读取最新备份的既有规则保持不变；历史恢复是额外的手动找回方式。旧电脑服务、连接失败、版本不匹配或备份内容无效时，会显示错误，不用空数据替换当前账本。

## 电脑构建兼容性验收

源码测试：`.venv/Scripts/python.exe scripts/test_backup_history_process.py`。先通过 `scripts/build_desktop.py` 构建，再加 `--packaged` 参数验证实际 `desktop/dist/LedgerBackup/LedgerBackup.exe`。测试使用独立模拟账号目录，保留v2旧快照和包含名称、规则及已确认商户的v5快照；拒绝越权规则后核对头版本与所有历史原文不变，再重启进程验证分页和下载。模拟目录保留在忽略的 `reports/private` 内。

2026-11-02本地构建已通过上述两种模式、41项服务测试、打包账号密码重启测试及GUI启动检查。此结论限于本机隔离测试，未验收公网通道、其他Windows机器或手机到新EXE的完整联调。公开Release尚未替换；本地构建仍沿用原版本标识，不应与公开同名旧程序混用。交付时必须保留EXE旁完整的 `_internal` 文件夹。
