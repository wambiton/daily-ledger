# 个人记账 0.7.15 · 公开试用版

本次整理并发布此前完成的改进，暂不增加新功能。欢迎小范围下载试用并提交反馈。

## 下载哪个文件

- Android：`PersonalLedger-Android-0.7.15.apk`。
- Windows：`PersonalLedger-Windows-0.7.15.zip`，完整解压后运行 `LedgerBackup/LedgerBackup.exe`。
- 想一次下载两端和说明：`PersonalLedger-Trial-0.7.15.zip`。
- 先阅读 `INSTALL.md`；`SHA256SUMS.txt` 用于校验附件完整性。

## 相比 0.7.14 的改进

- 电脑支持微信、支付宝 CSV/XLSX 与手机导出 JSON 对账，人工核实漏记后导出补记文件。
- 手机导入预览显示日期范围和收支合计，支持重复跳过或明确再次追加。
- 改善错误文件、损坏编码与不完整 JSON 的提示，清除旧的成功消息。
- 自动记账结果通知与待确认通知分开，补充命名规则说明。
- 补齐流量备份、历史独立恢复、邮箱验证码、注册和改密登录专项验收。

## 安装与数据保留

手机与电脑配套版本均为 0.7.15。手机选择覆盖安装，不要先卸载或清除数据；签名不兼容时停止安装并反馈。电脑退出旧程序及托盘后完整解压新版，保留 `_internal` 文件夹，检查账号数据目录仍指向原目录。不要把新版程序解压覆盖到账号数据目录。

QQ邮箱用于账号和验证码，账目保存在手机与用户自己的电脑，不在QQ邮箱中。发信邮箱及SMTP授权码由用户自行配置，下载包不含账号、授权码或真实账目。

## 试用边界

- Android 最低 8.0，APK 使用调试签名，目前主要在 realme GT7 验证，其他机型尚未全面验收。
- 自动记账依赖通知、短信和后台权限，可能漏记；不能保证所有微信、支付宝或银行交易均识别。银行短信主要适配招商银行95555模板。
- 电脑备份需要电脑开机、程序及连接服务运行。免费临时通道可能不稳定或变更地址，需要重新扫码。
- 换机只能找回已成功备份的记录；第二台物理手机、其他Windows电脑的完整流程仍待验收。
- 历史恢复生成独立账本供核对；配套不代表手机与电脑实时双向同步。
- 动漫主题素材的授权边界见仓库说明；本次试用发布不授予第三方素材再分发或商业使用许可。
