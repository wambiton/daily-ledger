# 个人记账电脑备份 · 免费试用版

## 给其他用户安装

1. 将交付包中的电脑端压缩包发给对方。完整解压后双击 `LedgerBackup.exe`，不要只复制EXE，也不需要另装Python、USB驱动或手机插件。
2. 在电脑程序中填写自己的QQ发信邮箱和SMTP授权码并保存；邮箱需开启SMTP服务。授权码由Windows加密保存在该电脑，不发送到开发者电脑。
3. 点击“保存设置”后会自动启动连接服务，等待显示二维码；已保存过授权码时无需重新填写，直接点击保存即可。也可手动点击“启动外网备份”。
4. 手机安装配套记账APK，进入“我的 → 扫码连接电脑”，允许相机权限后扫描二维码。
5. 在自己的电脑服务上注册QQ邮箱账号或登录已有账号。新注册会带入手机本机账目；点击“备份到电脑”才上传。

首次使用且没有已有数据时，账号和备份数据库位于该Windows用户的 `%LOCALAPPDATA%\PersonalLedgerBackup`。新版会识别同项目下的原账号目录，并记住所选数据目录；窗口顶部显示实际位置，“打开数据文件夹”可直接查看。每台电脑独立保存，不使用开发者的账号中心。

已有账号却无法登录时，先检查窗口显示的账号数据目录。可点击“选择原账号数据目录”，选择包含原 `accounts.sqlite3` 的文件夹；两处数据都保留，不会自动合并或覆盖。QQ邮箱SMTP授权码是电脑发邮件用的，不是手机账号密码。账号和备份不定期过期，登录凭据过期只需重新登录。

找回密码时需输入两遍新密码，至少8个字符，不限制字符类型；可用“显示 / 隐藏”核对。当前电脑目录没有该账号时，会明确提示密码未修改，不会再虚假提示成功。

授权码保存后输入框会清空，但下方会持续显示“已保存，无需重复输入”，重新打开程序仍能看到。保存状态与验证结果分开：“验证发信配置”只检查QQ邮箱认证，不发送邮件；认证通过仍需实际发送并收取验证码。修改设置并保存会重启连接，生成二维码后请手机重新扫码。连接超时会明确显示失败，原授权码保留。电脑程序不会随开机自动运行。

## 当前项目电脑

双击项目根目录“打开电脑备份.cmd”。此入口使用项目原有的“电脑账目备份\账号服务”目录，并兼容已保存的SMTP配置和账号数据。其他用户使用分发EXE时默认使用自己的Windows数据目录。

## 日常使用

- 手机可使用流量或Wi-Fi，无需USB。电脑需开机、联网并保持备份程序运行。
- 电脑窗口右上角关闭后缩到系统托盘，仍可接收备份；在托盘菜单选择“退出程序”才完全退出。不设置开机自启动。
- 电脑表格显示各账号最近成功备份的时间、笔数和版本。尚未到达电脑的失败请求无法出现在此表格中，手机会显示等待或失败原因。
- 手机手动发起一次备份后，电脑不在线会后台重试，通知提供取消按钮。锁屏或切到其他应用仍保留任务；具体重试时间受Android调度和省电限制影响。强行停止应用后需重新打开。
- 请允许通知权限，以显示后台备份状态；拒绝权限时仍可在“我的”查看状态与取消任务。
- 上传期间新增的账目不会覆盖丢失，但可能需要再点击一次备份，页面会提示。

## 更换地址、手机或电脑

免费临时外网地址可能在电脑程序重启后改变。重新扫描二维码更新地址；同一台电脑有固定身份，因此账号和手机账本不因网址变化而改变。旧地址已失效时，后台任务不能猜到新地址，必须重新扫码。

扫码本身不会上传账目。连接不同电脑前会提示确认，原手机账本继续保留。手机“我的 → 查看 / 切换手机账本”可以离线打开“扫码前的账号账本”或“原本机账本”，无需先登录；重新登录同一账号会复用原账本，不用电脑旧备份覆盖手机未上传修改。

若登录了另一台电脑上的账号，可先选中原手机账本，再点击“将这份手机账本追加导入当前账号”。完成后返回当前账号账本，点击“备份到电脑”。重复导入会先提示确认，原账本始终保留。

换手机：扫描原电脑二维码，用原QQ邮箱账号登录，自动加载最近成功上传的账目。未备份的修改仍只在原手机。

换电脑：扫描新电脑二维码，一次连接一台电脑；在新电脑重新注册QQ邮箱账号后，带入手机当前账目。原手机账本保留；原电脑上的备份不会自动转移或删除。

“导入原本机账目”是追加操作。重复时会询问，确认继续则新增相同账目，两笔都计入统计。

## 试用限制

使用Cloudflare免费临时HTTPS隧道，不需要购买服务器、域名或另外注册连接服务账号。官方将其定位为测试用途，不保证连续可用；部分网络可能无法访问。若连接失败，可停止服务后重试并重新扫码。

备份文件保存在用户自己的电脑，网络传输会经过隧道服务商。电脑端没有上传到开发者电脑的功能。

这是试用分发包，尚未完成所有Android机型兼容性和正式发布签名验收。多台手机同时编辑同一账号造成的备份版本冲突，会保留手机账目并拒绝旧版本覆盖，暂不自动合并。
