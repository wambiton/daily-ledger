# 用户自有电脑外网备份（2026-09-12确认）

用户要求：免费；手机只安装记账应用；Windows程序手动启动、关闭窗口进入托盘、可完全退出；每台电脑独立管理QQ账号及SMTP、多账号账目隔离。扫码配对，临时地址改变后可重新扫码；换电脑重新注册并带入当前手机账目。备份手动触发，离线后台等待、通知可取消。电脑展示各账号最新备份时间、笔数、结果。

## 实施顺序

1. E1：验证免费HTTPS隧道；独立电脑身份、二维码能力密钥和接口鉴权；服务端测试。
2. E2：Windows图形程序、DPAPI配置、托盘、自动隧道、账号备份列表；构建可分发包并测试。
3. E3：Android扫码配对、稳定电脑身份（地址变化不更换账本）、切换电脑携带当前账目；单元/真机测试。
4. E4：持久化后台上传任务、离线重试、持续通知及取消；防止跨账号/电脑误传；真机回归。
5. E5：隔离测试账号外网端到端、手机流量实际验收、用户操作说明和交付包。

每阶段测试并本地Git提交，个人数据、密钥、运行日志和构建安装包不进入Git。现有真实账目不作为测试数据。

## 边界

Cloudflare Quick Tunnel免费临时地址仅作为试用通道，不承诺连续可用；每次启动外网地址可能变化，扫码更新。同一电脑永久ID保持不变。无公共账号中心，服务端数据只保存各自电脑；流量会经过HTTPS隧道提供商。
Android后台任务由系统调度，省电策略可延后重试；强行停止应用后需重新打开。避免将无限等待实现为无限前台服务，Android 15对dataSync有时间限额。
