# 外观与主题

入口：我的 → 外观与主题。

- 默认主题：保留原有蓝白配色，与冬日主题共用新版首页布局。
- 雪乃·冬日：冰蓝、白色、深蓝文字；顶部圆形人物头像与预算旁Q版人物，当前账本本月收入/支出/结余、当前预算计划进度，下方按日期倒序列出账目。
- 点击“使用此主题”立即生效，选中的主题显示“正在使用”；随时可切回默认。设置保存在本机，应用重启仍保留，切换账号不改变外观，不随账号备份上传。
- 多月预算不平摊成虚构的月预算，卡片明确展示起止月份及整期预算；未知主题设置回退默认。
- 主题只改变展示，不导入、删除或修改账目，不改变记账、通知读取、分类、预算提醒或备份规则。

## 图片来源

`android/app/src/main/res/drawable-nodpi/winter_yukino.png` 与 `winter_characters.png` 为本次使用内置图像生成工具制作的雪乃主题插画，包含动画风人物与Q版人物，非官方素材或动画正片截图。用户提供的社交平台截图只作为视觉参考，没有将网页按钮、作者信息或示例账目打包进应用。文字、金额、进度均由原生界面渲染，图片不承载实际账目数据。

版本：Android 0.7.4-winter-polish（15）。电脑备份程序继续使用0.7.0，协议未变。

## 统一首页排版

两个主题共用“标题与头像→收支卡片→紧凑预算卡片→日历/搜索并排入口→按日期分组账目”的结构。今天固定置顶，其他日期倒序，列表按需渲染；不把示例金额写入实际界面。默认主题以账本符号代替人物，冬日主题提供人物装饰。

点击日历打开月份视图，可以切换月份、选日期查看账目或补记；历史账目详情返回该日期，回到今天按钮保留。没有预算时仍可点击预算卡片创建计划；多月计划明确显示“本期预算”和起止月份。新增矢量导航/分类/工具图标。

## 参考图视觉细节补齐

冬日主题使用独立的全屏雪景 `winter_landscape.png`（本次AI生成的无人物、无文字背景），不再从人物横幅裁出近乎不可见的背景。卡片保留浅色底保证文字可读；页头、收支卡、预算旁和列表末尾增加参考图中的装饰语句。

金额采用系统窄体数字、加粗层次、较小人民币符号及千分位。装饰语句使用衬线斜体效果；生成预览不是字体文件，实际字体表现仍由安卓系统渲染，不声称与图片逐像素一致。

默认和冬日主题均显示预算已使用百分比，按真实支出/预算计算并四舍五入到整数；超预算显示实际超过100%的比例，进度条最多填满。未设置预算时不伪造百分比。默认主题保留简洁背景和配色。


## 0.7.5 页面统一
日历增加所选月份收入/支出及日期下每日支出，今天描边、选中日期实色；保留历史明细和补记。比较页将多周期选择集中在卡片，突出金额及比例，分类按各期合计排序。我的页保留备份状态和账号操作，工具改为图标列表，外观与主题移到偏好设置。默认主题保持清爽，冬日页头使用雪景及人物。


## 0.7.6 独立人物插画
比较页使用winter_comparison.png（拿笔阅读的Q版），账号卡使用winter_profile.png（用户确认的柔和冬装捧茶版）；未使用后来生成的动画平涂版。两张为内置图像生成工具创建的插画，不是动画原片。仅冬日主题显示，80dp圆角区域完整适配，账本和日历素材不变。


## 0.7.7 信息层级精简
我的页首屏为账号与当前账本摘要、备份快捷操作和本机保存状态；登录/注册/密码重置、扫码连接、账本切换、导入及退出账号统一进入“账号、连接与账本管理”。保留原有数据隔离和备份逻辑。比较页默认收起完整周期编辑，显示前两个周期与额外周期数量；点击“调整比较周期”展开全部选择，收起不会丢失选择。周/月和收入/支出切换仍直接可见，比较结果更早出现。
